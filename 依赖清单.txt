云铸 / Agnes Harness 依赖清单
整理日期：2026-10-14
适用主流程：Windows x64，AGH + C++ RANSAC 检测 + CadQuery CAD + 当前输入核验。
所有安装 / 构建步骤与权限配置详见同目录“复现指南.md”。

一、必须安装的工具链
1. Git
   下载：https://git-scm.com/downloads/win
2. Node.js >= 24.10，建议与已有项目环境记录 24.21.0 匹配，x64。
   下载：https://nodejs.org/en/download
   AGH 约束见 agnes-harness/package.json。
3. pnpm 10.34.5
   安装：npm.cmd install --global pnpm@10.34.5
   文档：https://pnpm.io/installation
4. Visual Studio 2022 / Build Tools
   勾选“使用 C++ 的桌面开发”、MSVC x64 工具集与 Windows SDK。
   下载：https://visualstudio.microsoft.com/downloads/
   从 VS 的 x64 Developer PowerShell 构建。
5. CMake >= 3.15
   下载：https://cmake.org/download/
6. Python 3.12 x64（建议带 Python Launcher）
   下载：https://www.python.org/downloads/windows/

二、已有源码 / 固定依赖依据
- CloudForge 前端：CloudForge/package.json + package-lock.json；npm.cmd ci 安装。
  主要库：Vue 3、Three.js、Vite、TypeScript、Tauri 2。
- AGH：agnes-harness/package.json + pnpm-lock.yaml + pnpm-workspace.yaml + patches/。
  pnpm.cmd install --frozen-lockfile；必须保留 workspace 补丁配置与补丁文件。
  使用本仓库随附 modified AGH，不要另外检出早期上游提交替换它。
- Eigen 5.0.1：CloudForge/src-tauri/cpp/third_party/eigen-5.0.1/ 已包含。
  保留各许可文件，通常无需另外下载。
- RANSAC_SD：不随仓分发，研究用途授权，复现者自行获取并遵守许可。
  来源：https://github.com/CloudCompare/CloudCompare/tree/master/plugins/core/Standard/qRANSAC_SD/extern/RANSAC_SD
  放入 CloudForge/src-tauri/cpp/third_party/ransac_sd/。
  完整源码需含 CMakeLists.txt 并提供 QRANSAC_SD_PRIM_SHAPES_LIB 目标。
  本次环境未记录其精确上游提交，获取时请记录提交号并核对 API 兼容性。

三、CAD Python 核心版本
cadquery==2.6.1
numpy==2.2.6
scipy==1.15.3
核心清单：CloudForge/hackathon/tools/requirements-cad.txt
完整 Windows / Python 3.12 版本快照：CAD依赖锁定-Windows-Python312.txt（同目录）
安装示例（从 CloudForge 执行）：
  py -3.12 -m venv .venv-cad
  .\.venv-cad\Scripts\python.exe -m pip install -r ..\CAD依赖锁定-Windows-Python312.txt
虚拟环境需本机重新创建，不复制旧电脑的 .venv-cad。
完整快照与核心清单二选一；优先快照以匹配当前间接依赖。

四、AGH Windows 原生依赖
原生 helper 使用 MSVC + 与实际 Node 版本一致的 Node headers / node.lib。
在 agnes-harness 目录、VS x64 开发终端执行：
  $taskNodeVersion = node -p "process.versions.node"
  $taskNodeArch = node -p "process.arch"
  $taskNodeCache = Join-Path $env:LOCALAPPDATA 'node-gyp\Cache'
  npm.cmd exec --yes --package=node-gyp -- node-gyp install "--target=$taskNodeVersion" "--arch=$taskNodeArch" "--devdir=$taskNodeCache"
  pnpm.cmd --filter @agnes/cli build:local
不要只复制 agnes.mjs；完整运行目录为 packages/cli/dist/local/。

五、可选依赖
- Rust stable MSVC：仅构建 CloudForge Tauri GUI 时需要。
  下载：https://rustup.rs/
  Rust crates 由 CloudForge/src-tauri/Cargo.lock 锁定，cargo 在构建时下载。
- Windows WebView2：Tauri 桌面端需要的系统运行组件，按 Tauri Windows 前置要求准备。
- FreeCAD：用于外部 FreeCAD 打开 / 额外检查；网页 CadQuery 预览与基本 STEP 生成不要求它。
  下载：https://www.freecad.org/downloads.php
- WSL / 第三方语义实例分割模型：属于另一条可选桌面入口，不是 AGH + RANSAC 核心演示的依赖。

六、运行与首次配置要点
1. 从 CloudForge 启动：
   node ..\agnes-harness\packages\cli\dist\local\agnes.mjs serve --port 4177
2. 使用自己的 AGH 模型账号 / 密钥，网页地址 http://127.0.0.1:4177/。
3. 用户 profile 的 policy.capabilityCeiling 需在原列表中加入 services；不能由工作区扩大该权限。
4. 信任当前 CloudForge 工作区；构建并安装 cloudforge-tools 和 cloudforge-panel。
5. 检查 / 信任 / 启用随仓 cloud-casting Skill。
6. 小样本在 CloudForge/hackathon/demo-data/，完整点云在 data/；无需先批量扫描完整数据。

七、没有随仓包含的内容
node_modules、pnpm 缓存、Rust target、CMake build、Python 虚拟环境、个人 AGH home、
API 密钥、私人会话 / 执行数据库以及不允许再分发的 RANSAC 原始库。
它们不是遗漏的源码：依赖通过锁文件安装，产物从当前源码构建，账号由接收者自行配置。
历史 demo metadata 可能含旧路径；需对当前点云重新生成结果，不将旧 PASS 当作新核验结论。
