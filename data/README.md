# Demo data sources

These files are demo inputs, not project-owned assets. They keep their upstream terms and are not relicensed under CloudForge's Apache-2.0 license.

| Path | Source | Terms |
| --- | --- | --- |
| `livingroom1-fragments-ply/`, `office1-fragments-ply/` | [Redwood / 3DMatch indoor scans](http://redwood-data.org/3dscan/) | Follow the upstream dataset terms. |
| `DemoColoredICPPointClouds/` | [Open3D sample data](https://www.open3d.org/) | Follow the Open3D data terms. |

Synthetic point clouds used by the tests and demo are generated by the project and live under `CloudForge/hackathon/demo-data/`. See the root README and `CloudForge/hackathon/declaration.md` for the complete inventory.
