# Desktop specification records

These files document the original Tauri desktop GUI and its AI-runner integration. They are retained as design and implementation records, not as setup instructions for the AGH workbench.

Paths such as `E:/C++/Point/...` and `/mnt/e/C++/Point/...` refer to the original development workstation. A fresh clone does not depend on them; use project-relative paths or your own workspace. The current setup and run instructions are in the root [README.md](../../../README.md), [复现指南.md](../../../复现指南.md), and [CloudForge/hackathon/ONBOARDING.md](../hackathon/ONBOARDING.md).
