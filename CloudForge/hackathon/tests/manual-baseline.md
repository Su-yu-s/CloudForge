# 人工基线实测方案（量化价值表的"人工"一栏）

目的：给价值对比表补上"传统人工流程"的实测耗时。总耗时约 15–20 分钟，建议录屏
（既是计时依据，也可剪进演示视频作"传统方式"对照镜头）。

## 测量设置

- 工具：CloudCompare（或任意点云软件）+ 秒表
- 数据：`E:/C++/Point/data/livingroom1-fragments-ply/cloud_bin_0.ply`（与云铸 N2 同一份数据）
- 任务：模拟测量员对点云做"墙体/地面参数提取"，完成 **3 个平面**的全流程
  （选中点云区域 → 拟合平面 → 记录方程/法向/偏差 → 汇总进表格）

## 计时步骤（每个平面重复一次，分别记录）

| 步骤 | 计时起止 |
|---|---|
| 1. 旋转/缩放定位到目标面（墙、地板、桌面各一） | 开始 |
| 2. 圈选该面的点（避免带入邻近物体杂点） | |
| 3. 拟合平面（CloudCompare: Fit plane） | |
| 4. 读取并抄录参数（法向量、原点距、RMS）到 Excel | 结束 |

## 换算与呈现

- 单面均值 t = 三次计时平均；41 个平面总耗时 ≈ t × 41（如 t=3min → 约 2 小时），
  报告中标注"以 3 面实测均值外推"；
- 对照行填云铸实测：**1.0 s 检测 43 平面 + 一次对话 ~2 min 出报告**（suite-result.json）；
- 第三行"参数可信度"：人工抄录易错 vs 每基元自带 RMSE/σ/软评分。
