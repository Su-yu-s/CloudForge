# AGH execution evidence

This directory keeps the execution evidence used during the live run:

- `agh-trajectory-web.json` — AGH execution events in JSONL form (one event per line).
- `agh-trajectory-web.html` — rendered trajectory view.
- `panel/` — screenshots captured while integrating and testing the CloudForge panel.

The trajectory files were produced by a real AGH session, not generated by hand. Before publication, operator IDs, account routes, session keys, and local filesystem paths were normalized to neutral values. Event order, timestamps, tool names, approvals, and result counts are unchanged.

No model keys, passwords, tokens, or personal account identifiers are stored in this directory.
